# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
**Security → Report a vulnerability** flow for `fibegg/sdk` to create a private
security advisory. Include affected versions, impact, reproduction steps, and
any suggested mitigation. Remove API keys, tokens, and customer data.

Maintainers will acknowledge a complete report as soon as practical, assess
supported versions, coordinate a fix and disclosure, and credit reporters who
request attribution. Please allow time for remediation before public
disclosure.

## Supported versions

Security fixes target the latest `0.2.x` release until a newer supported line
is announced in `SUPPORT.md`. Older releases may receive a fix only when the
same patch applies safely.
